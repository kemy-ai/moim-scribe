# Deliverable: meeting minutes

## Structure

```
# Minutes — [topic]

## Overview
- Topic:
- Attendees: N — names/labels (take the count from the "Speaker stats" data above; never guess from the conversation)
- When: use the recorded-at time from "Recording info" above; an explicit date/time mentioned in the transcript wins

## Attendance and talk share
Build the table from the "Speaker stats" data (talk_sec, share):
| Speaker | Share |
|---|---|
| Name | NN% |

## Key discussion
Per agenda item, show the flow with arrows:
- **[item]**: problem raised → discussion → where it landed

## Decisions
- (confirmed items only — "agreed to do X")

## Action items
- [owner] what (include deadline if mentioned)

## Parked / next time
- (unresolved items, things deferred)
```

Keep decisions and parked items strictly separate. "Let's look into it" is an action item or parked — not a decision.
