# Deliverable: gathering notes

For book clubs, writing circles, and similar recurring gatherings. The point
is preserving each participant's thinking and insights — not decisions
(that's what meeting minutes are for).

🔴 **Length scales with the recording.** Never compress a long (2h+) gathering
into one screenful. Don't flatten each thread into a single line — write it so
the arc shows (what happened → what was weighed → what advice or conclusion
followed). Cut by "not important", never by "too long".

## Pick a shape first

- **Agenda-led** — the group follows a book, a writing prompt, a set topic (book clubs, writing circles): use **Structure A**
- **Open-ended** — catch-up and conversation with no set topic (use this when the transcript shows no book or agenda being worked through): use **Structure B**. Here per-person catch-up is the centre of the deliverable; a topic-by-topic list reads like meeting minutes and does not fit this kind of gathering

## Structure A (agenda-led)

```
# [group name] discussion notes — [date/round]

## Overview
- Topic: (book, writing prompt, theme)
- Attendees: N — names (count comes from the "Speaker stats" n_speakers / filename hint; never guess from the conversation)
- Flow: (one arrow line for the whole session — e.g. catch-up → ratings → discussion → next book)
- Ratings: (if ratings were mentioned — average X.X — Name 9.0 / Name 8.5 … one line; omit otherwise)

## Attendance and talk share
Build the table from the "Speaker stats" data (talk_sec, share). Keep labels for unidentified speakers:
| Speaker | Share |
|---|---|
| Name | NN% |

## What was discussed
Per topic, what was actually said:
- **[topic]**: essence of the discussion

## Memorable lines
Per speaker, quotes worth keeping (verbatim):
- SPEAKER_NN: "…"

## Insights
- (perspectives and takeaways that emerged)

## Next time
- (next book/topic/homework if mentioned)
```

Don't flatten everything into a summary — where opinions diverged, show the disagreement.

## Structure B (open-ended — per-person cards)

```
# [group name] notes — [date]

One line: (what kind of gathering this was, the mood)

## Attendance and talk share
(same as Structure A — from the "Speaker stats" data, never guessed)

## Per person
### [name]
- News: (what's new, how they're doing)
- On their mind: (what they aired, and the gist of the advice they got)
- Ask next time: (the thing whose outcome you'd want to hear about when you next meet)

## Topics worth keeping
- **[topic]**: the essence only — not an exhaustive list, 3-6 threads that are worth remembering

## Insights
- (what today's conversation yields — the principle behind the advice, a pattern that recurred, something learned)

## Memorable quotes
- Name: "…" (verbatim)

## Next time / commitments
- (dates, invitations, who agreed to do what)
```

🔴 **Structure B, important**: never file an unidentified label's (SPEAKER_NN)
speech under a named person's card by guessing. Only speakers whose real name
is established get a card; unidentified speech belongs in the topics section.
The per-person card format forces a decision about who said what, which makes
guessed attribution a bigger risk here than in the other shape.
