# Demo book club (예제 팩 — 전부 가상의 인물)

> This is a synthetic example pack. Copy this directory, rename it, and
> replace everything below with your own group. All names are fictional.

## 모임 성격 / About

- 격주 수요일 저녁, 소설 한 권씩 읽는 4인 북클럽 (fictional biweekly book club)
- 진행 순서: 근황 → 평점 공유 → 자유 토론 → 다음 책 선정

## 참가자 명단 / Roster

- 김하늘 (Haneul) — 모임장, 평점을 먼저 말하는 편
- 이바다 (Bada) — 인용을 즐겨 함
- 박구름 (Gureum) — 반론 담당
- 최별 (Byeol) — 조용하지만 마무리 발언이 김

## 특이사항 / Notes

- 평점은 10점 만점
- 다음 책은 항상 모임 마지막 10분에 정한다
